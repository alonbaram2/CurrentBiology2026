# ManyMaps

This repo contains data and code for Baram et al. (2026)
https://www.cell.com/current-biology/fulltext/S0960-9822(26)00673-1

# System requirements

The code was developed using Python 3.11, and Matlab2020b. Certain files are run in Jupyter Notebooks. 

# Instructions for use
Files to run the GLM and define the contrast images as well as scripts to reproduce the images reported in the paper can be found in the folder Scripts. 

Data contains raw behavioural data (alldata), arena task data (arena), parameter estimates extracted from various ROIs (ROI), data RDMs for RSA analyses, and T-maps as found in the paper.
